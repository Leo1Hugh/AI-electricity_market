## 0. 一句话

把 **2023-11-01 至 2026-10-31** 的 CAISO SP15 日前价格与日前负荷/风光预测，做成一张
**1096 天 × 24 小时 = 26304 行、88 列** 的长表面板；W2 只依赖这张表和本文件定义的模型/回测接口。

## 1. 时间、时区、颗粒度

| 项 | 契约 |
| --- | --- |
| 市场 | CAISO 日前市场（DAM） |
| 节点 | **TH_SP15_GEN-APND** |
| 价格 | LMP_TYPE=LMP，MW 字段即 USD/MWh |
| 运行日 D | 加州当地时间（America/Los_Angeles）的交易日 |
| 小时 | **OPR_HR = 1..24**，对应 HE1..HE24 |
| 主键 | **(day, hour)**，全表唯一 |
| 训练范围 | 2023-11-01 ～ 2026-10-31 |
| 比赛范围 | 2026-11-23 ～ 2026-12-06（北京时间次日 02:00 截止） |

**夏令时规则（硬性）**：

1. 秋季回拨日（2023-11-05、2024-11-03、2025-11-02）原始数据有 **OPR_HR=25**。面板**丢弃 hour=25**，只保留 1..24。
2. 春季跳过日（2024-03-10、2025-03-09、2026-03-08）原始数据缺 **OPR_HR=3**。面板**保留 hour=3 这一行**，其 y 为 NaN，其余特征按当天日前预测计算。
3. 禁止按行号 shift；所有滞后一律按**日历日**对齐。

| --- | --- | --- | --- |

| 组 | 数量 | 列 |
| --- | --- | --- |
| 主键 | 2 | day, hour |
| 目标 | 1 | y |
| 价格滞后 | 14 | p_lag1..7, p_lagmean7, p_lagstd7, p_lag1_prev, p_lag1_next, p_lag1_daymean/max/min |
| 外生 | 13 | load_caiso, load_sce, load_sdge, solar, wind, netload, nl_ratio, nl_ramp, nl_daymean, nl_daymax, sol_sum, sol_ratio, load_ramp |

**地理口径警告**：load_caiso 是 CAISO TAC 总负荷，solar/wind 是 SP15 交易枢纽预测；两者地域不完全一致。
netload = load_caiso - solar - wind 是**代理净负荷**，不是物理口径。它只作为特征使用，报告中必须写明这一点。

## 4. 特征公式

记：

- P[d,h]：D 日 h 时的日前价格
- L[d,h]：load_caiso；C[d,h]：load_sce；G[d,h]：load_sdge
- S[d,h]：solar；W[d,h]：wind
- NL[d,h] = L[d,h] - S[d,h] - W[d,h]

对每一行 (d,h)：

| 特征 | 公式 |
| --- | --- |
| p_lag{k}, k=1..7 | P[d-k, h] |
| p_lagmean7 | mean(P[d-1..d-7, h]) |
| p_lagstd7 | std(P[d-1..d-7, h], ddof=0) |
| p_lag1_prev | P[d-1, h-1]（h=1 时取 P[d-1,24]） |
| p_lag1_next | P[d-1, h+1]（h=24 时取 P[d-1,1]） |
| p_lag1_daymean | mean_h P[d-1, :] |
| p_lag1_daymax / daymin | max_h / min_h P[d-1, :] |
| load_caiso / load_sce / load_sdge | L[d,h] / C[d,h] / G[d,h] |
| solar / wind | S[d,h] / W[d,h] |
| netload | NL[d,h] |
| nl_ratio | NL[d,h] / L[d,h] |
| nl_ramp | NL[d,h] - NL[d,h-1]（h=1 时减 NL[d,24]） |
| nl_daymean / nl_daymax | mean_h / max_h NL[d, :] |
| sol_sum | sum_h S[d, :] |
| sol_ratio | sol_sum / mean_h L[d, :] |
| load_ramp | L[d,h] - L[d,h-1]（h=1 时减 L[d,24]） |
| dow | day.weekday()，周一=0 |
| month / doy | 月 / 年内日序 |
| is_weekend | dow >= 5 |
| is_holiday | 是否美国联邦假日（见下） |
| d_to_holiday | 到最近假日的天数绝对值，**上限 30** |
| is_thanksgiving | 是否感恩节（11 月第 4 个星期四） |
| is_black_friday | 是否黑色星期五（感恩节次日） |
| is_pre_holiday | 次日是否为假日 |
| is_post_holiday | 前一日是否为假日 |
| x_p1_{hh} | P[d-1, hh]，hh=1..24 |
| x_nl_{hh} | NL[d, hh]，hh=1..24 |

**假日集合**：元旦、MLK（1 月第 3 个周一）、总统日（2 月第 3 个周一）、阵亡将士纪念日（5 月最后一个周一）、
六月节（6/19）、独立日（7/4）、劳动节（9 月第 1 个周一）、哥伦布日（10 月第 2 个周一）、
退伍军人节（11/11）、感恩节（11 月第 4 个周四）、圣诞节（12/25）。
周六假日观察到周五，周日假日观察到周一；跨年按观察日处理。
黑色星期五不是联邦假日，单独用 is_black_friday 标记，is_holiday 仍为 0。

**NaN 规则**：

- 价格无缺测；若未来出现缺测，滞后特征保留 NaN，**禁止双向插值**。
- 风光缺测三天：2024-03-09、2025-03-08、2026-03-07；对应 solar/wind/netload 等保留 NaN。
- 训练时由模型自行处理 NaN；Ridge 用**训练集中位数**填充，LightGBM 原生处理。
- 禁止 ffill/bfill 跨越缺测日去"补"预测值；如需填充，只能使用**当天之前**的信息，并在报告中说明。

## 5. 模型接口

所有逐行模型实现同一个协议（**src/em/models/base.py**）：

~~~python
class Regressor(Protocol):
    name: str
    def fit(self, X: pandas.DataFrame, y: pandas.Series) -> "Regressor": ...
    def predict(self, X: pandas.DataFrame) -> numpy.ndarray: ...
~~~

必须提供的类与构造签名：

| 类 | 文件 | 构造 | 说明 |
| --- | --- | --- | --- |
| NaiveD1 | src/em/models/naive.py | NaiveD1() | predict 返回 X["p_lag1"] |
| NaiveD7 | src/em/models/naive.py | NaiveD7() | predict 返回 X["p_lag7"] |
| NaiveMean7 | src/em/models/naive.py | NaiveMean7() | predict 返回 X["p_lagmean7"] |
| RidgeModel | src/em/models/ridge.py | RidgeModel(alpha=10.0) | 中位数填充 + 标准化 + Ridge |
| LGBMModel | src/em/models/lgbm.py | LGBMModel(params=None) | LightGBM 回归，固定 random_state=0 |

约定：
- **fit 只能看见训练集**；填充值、标准化参数都必须在 fit 内从训练集学习。
- predict 返回长度等于 X 的一维 float 数组，不允许 NaN（输入特征全 NaN 的行，模型应给出有限值或明确报错）。
- 模型不负责排序、不去重；输入输出按行对齐。

## 6. 回测协议

### 6.1 滚动原点（年度评估）

文件：**src/em/backtest/harness.py**

~~~python
def monthly_walk_forward(panel, model_factory, features, start, end) -> BacktestResult
def fixed_window(panel, model_factory, features, window_start, window_end) -> BacktestResult
~~~

- monthly_walk_forward：从 start 所在月到 end 所在月，每月一个 fold；训练集 = **day < 该月第一天** 且 y 非空；测试集 = 该月内且不超过 end、y 非空。
- fixed_window：一个 fold；训练集 = **day < window_start** 且 y 非空；测试集 = [window_start, window_end] 且 y 非空。
- **禁止**：随机 KFold、shuffle、用测试月数据做填充/标准化/调参。
- 每次调用 model_factory() 生成一个**全新**模型；不得复用已 fit 的对象。
- 返回：

~~~python
@dataclass
class BacktestResult:
    predictions: pandas.DataFrame   # 列：day, hour, y, pred, model
    folds: pandas.DataFrame         # 列：model, train_start, train_end, test_start, test_end, n_train, n_test
~~~

- predictions 必须覆盖测试集中所有 y 非空的行；pred 不得为 NaN/inf。
- folds 中必须满足 train_end < test_start（逐 fold 断言）。

### 6.2 比赛同款窗口

模型选择必须至少报告：

1. 年度滚动：2025-11-01 ～ 2026-10-31，按月重训。
2. 冬季窗口 A：2024-11-23 ～ 2024-12-06，训练只用 2024-11-22 及以前。
3. 冬季窗口 B：2025-11-23 ～ 2025-12-06，训练只用 2025-11-22 及以前。

指标一律按**日 RMSE** 聚合，报告 mean / median / max / p90 / 崩盘日比例；不得用小时级 MAE 代替。

### 3.1 模型协议

~~~python
class Regressor(Protocol):
    name: str
    def fit(self, X: pandas.DataFrame, y: pandas.Series) -> "Regressor": ...
    def predict(self, X: pandas.DataFrame) -> numpy.ndarray: ...
~~~

- NaiveD1()：predict 返回 X["p_lag1"].to_numpy(float)
- NaiveD7()：X["p_lag7"]
- NaiveMean7()：X["p_lagmean7"]
- RidgeModel(alpha=10.0)：训练集内 median 填充 + StandardScaler + Ridge；fit 内学习，predict 复用
- LGBMModel(params=None)：LightGBM 回归；默认
  n_estimators=700, learning_rate=0.03, num_leaves=15, min_child_samples=40,
  subsample=0.9, subsample_freq=1, colsample_bytree=0.8, reg_lambda=1.0,
  random_state=0, verbose=-1, n_jobs=1；params 可覆盖默认值。

所有 predict 返回一维 float ndarray，长度等于 X，不得含 NaN/inf（Ridge 必须能处理含 NaN 的特征）。

### 3.2 metrics.py

~~~python
def daily_rmse(y_true: numpy.ndarray, y_pred: numpy.ndarray) -> numpy.ndarray
def summarize_daily_rmse(daily: numpy.ndarray, crash_threshold: float = 20.0) -> dict
def paired_block_bootstrap(diff: numpy.ndarray, block: int = 7,
                           n_boot: int = 10000, seed: int = 0) -> dict
~~~

- daily_rmse：输入 (n_days, 24)，输出 (n_days,)；某天全 NaN 输出 NaN。
- summarize：n_days / mean / median / max / p90 / crash_days / crash_rate；p90 用线性插值；crash 定义为 daily > crash_threshold。
- bootstrap：循环块（circular block），块长 block；返回 mean / lo / hi / p_two_sided；lo/hi 为 2.5/97.5 分位；p 上限 1.0。

### 3.3 harness.py

~~~python
@dataclass(frozen=True)
class Fold:
    model: str
    train_start: pandas.Timestamp
    train_end: pandas.Timestamp
    test_start: pandas.Timestamp
    test_end: pandas.Timestamp
    n_train: int
    n_test: int

@dataclass
class BacktestResult:
    predictions: pandas.DataFrame
    folds: pandas.DataFrame

def monthly_walk_forward(panel, model_factory, features, start, end) -> BacktestResult
def fixed_window(panel, model_factory, features, window_start, window_end) -> BacktestResult
~~~

- 训练集：day < test_start 且 y 非空；测试集：窗口内且 y 非空。
- monthly：从 start 所在月到 end 所在月，每月一个 fold；测试月上界不超过 end。
- 每次 model_factory() 新建模型；不得复用。
- predictions 列顺序：day, hour, y, pred, model；按 day,hour 排序。
- folds 列顺序：model, train_start, train_end, test_start, test_end, n_train, n_test。
- 每个 fold 断言 train_end < test_start；训练/测试 (day,hour) 不相交。
- 不得 shuffle、不得 KFold、不得用测试集统计量做填充/标准化。
