# AI-electricity_market

面向智慧电力与电力市场赛事的参赛项目仓库，统一整理电价预测和交易决策两个赛道的方案、实验与提交材料。

## 参赛信息

| 项目 | 信息 |
| --- | --- |
| 参赛形式 | 线上组 |
| 参赛赛道 | 电价预测、交易决策 |
| 当前阶段 | 方案与资料整理 |

## 项目目标

### 电价预测

建立可复现的电价预测流程，完成数据检查、特征构造、时间序列验证、基线模型和预测结果导出。验证时按时间切分数据，避免未来信息泄漏。

### 交易决策

基于历史市场信息和电价预测结果制定交易策略，完成回测、风险约束和收益评估。预测与策略部分使用一致的时间窗口，便于比较不同预测模型对交易结果的实际影响。

## 计划中的目录

```text
data/          # 本地数据或按赛事规则准备的数据，不提交敏感或受限数据
src/forecasting/  # 电价预测模型与评估
src/trading/      # 交易策略、回测与风险控制
notebooks/     # 探索分析与实验记录
configs/       # 实验配置
reports/       # 图表、结果和提交说明
```

## 当前仓库内容

- `焕新社区智慧电力专区.pdf`：赛事相关资料，供方案设计和规则确认使用。
- `data/CAISO/`：CAISO SP15 日前电价公开原始数据及采集清单，详见该目录的说明。
- `data/raw/caiso/`：CAISO OASIS 返回的原始负荷和风光预测 ZIP；`data/raw/caiso/errors/` 保存官方返回的无数据错误 ZIP。
- `data/caiso_collection_manifest.jsonl`：每次请求的日期范围、查询地址、获取时间、文件记录数和 SHA-256。
- `data/caiso_validation_report.md`：全量字段、时间、区域、重复、空值和目标日期覆盖核验报告。
- `data/caiso_collection_notes.md`：来源、字段口径、DST 处理、缺失范围和发布时间限制。
- `scripts/caiso_oasis_collect.py`、`scripts/verify_caiso_forecasts.py`：可复查的采集和核验工具。

仓库目前已加入 CAISO SP15 日前电价数据，以及负荷和风光预测数据；尚未加入训练代码或可直接运行的预测/交易 pipeline。赛事数据字段、评测指标和提交格式仍需按比赛规则补充基线与正式实验流程。

## 开发约定

- 所有验证按时间顺序进行，训练集和验证集不得使用未来数据。
- 预测赛道和交易赛道分别记录指标，同时保留从预测到策略收益的端到端结果。
- 除本次按用户要求纳入的 CAISO 公开原始电价数据外，其他原始数据、密钥和赛事受限文件不提交到 Git；实验配置和可复现实验结果应随代码记录。
