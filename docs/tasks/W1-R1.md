## 1. 背景（一句话）

W2 的所有模型都吃同一张长表：1096 天 × 24 小时 = 26304 行、88 列。
这张表错了，后面所有回测都作废。所以本任务的核心不是"跑通"，而是**可被断言推翻**。

日历特征口径见契约第 4 节。补充要求：

- 假日宇宙固定覆盖 **2022–2028**，与输入 days 的范围无关；这样截断重算时 d_to_holiday 不变。

### 3.2 src/em/data/panel.py

~~~python
def build_panel(hourly: pandas.DataFrame) -> pandas.DataFrame:
    """纯函数：不读文件、不写文件、不修改入参。"""
~~~

输入列至少包含 contracts.REQUIRED_HOURLY_COLUMNS。
输出列顺序严格等于 contracts.PANEL_COLUMNS。

实现要点（按顺序）：

1. 校验列；opr_dt 转 datetime64 并 normalize；opr_hr 转 int。
2. 只保留 1 <= opr_hr <= 24；按 (opr_dt, opr_hr) 去重，保留最后一条。
3. 日期轴 = 输入最小日到最大日的**连续日历日**，再裁剪到 [TRAIN_START, TRAIN_END]。
4. 用 pivot 得到 6 个 day×24 矩阵：P(price)、L(load_caiso)、C(load_sce)、G(load_sdge)、S(ren_solar)、W(ren_wind)；
   缺失小时补 NaN（不要丢行）。
5. NL = L - S - W。
6. 按契约第 4 节逐列计算 85 个特征；跨小时特征用 24 列广播。
7. 日历特征用 calendar_features(days)，再按小时广播。
8. 拉成长表：day 用 np.repeat，hour 用 np.tile；所有矩阵用 .to_numpy().ravel()，保证 day-major / hour-minor 对齐。
9. 返回 long[list(PANEL_COLUMNS)]，按 (day, hour) 排序，reset_index。

**绝不允许**：

- 双向插值 / bfill / 用未来日填充（interpolate(limit_direction="both") 是禁的）。
- 按行号 shift；必须按日历日 shift。
- 对 y 做任何平滑、截断、替换。
- 丢弃春季缺小时的整行；必须保留 hour=3 且 y=NaN。
- 保留秋季 hour=25。

## 4. 验收（Lead 会逐条跑）

~~~powershell
$env:PYTHONPATH="src"
python -m pytest -q tests/test_contracts.py tests/test_panel_contract.py tests/test_calendar.py
python scripts/build_panel.py --input work/hourly.csv.gz --output data/processed/panel.csv.gz
~~~

必须满足：

- [ ] 26304 行、1096 天、24 小时、88 列
- [ ] (day, hour) 无重复
- [ ] p_lag1/p_lag7 与 P.shift(1/7) 逐元素相等（NaN 位置也一致）
- [ ] 截断重算：只用 <=2024-03-09 和 <=2025-11-23 的原始数据重建，目标日特征完全一致
- [ ] 秋季三天 hour=25 被丢弃；春季三天 hour=3 存在且 y 为 NaN
- [ ] 三个风光缺测日 solar/wind/netload 保留 NaN
- [ ] 2024-11-28 感恩节、2024-11-29 黑五、2024-11-27 假日前一天 标记正确
- [ ] netload == load_caiso - solar - wind（NaN 对齐）
- [ ] x_p1_hh 与对应小时的 p_lag1 一致
- [ ] 无 inf；y 非空 26304 行
- [ ] 构建报告由脚本生成，不是手写
